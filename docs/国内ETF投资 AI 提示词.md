## 国内ETF投资 AI 提示词

****

## 改造的核心逻辑：从“分析公司”切换到“分析工具”

上一轮报告中的提示词以个股为默认对象，其底层假设是“公司有内在价值，分析的任务是判断价格与价值的关系”。ETF没有这一层假设。ETF分析的核心判断被概括为两条：**指数便宜吗 + 产品好不好**。前者指向所跟踪指数的估值与景气位置，后者指向跟踪质量、费率、流动性、集中度等工具属性。

因此，改造不是简单地把“股票”替换成“ETF”，而是重新设计每条提示词的任务目标、输入字段、判断标准和输出约束。以下按四类场景逐一给出可直接使用的版本，并在每条后注明改造要点

## 一、筛选与机会发现类：从“产业链荐股”改为“指数—产品双层收敛”

### 1.1 主题/行业ETF筛选（替代原“产业链延伸筛选”）

**可直接使用的提示词：**

> 你是一位熟悉A股ETF产品谱系的研究助理。围绕 **{主题/行业}** ，在**排除该主题下规模最大的前3只ETF之后**，从全市场筛选出3只值得进一步研究的场内ETF。对每只输出：
> 
> 1. 代码、名称、跟踪指数名称及代码；
> 2. 跟踪指数近3年PE/PB历史分位（注明数据口径：近3年/近5年，周频/日频）；
> 3. 最新规模（亿元），判断是否处于 **>50亿 / 10—50亿 / 2—10亿 / <2亿** 区间，<2亿须标注“清盘警戒”；
> 4. 管理费+托管费合计费率，并与该类型ETF的行业均值对比（宽基/行业/主题/债券分别对照）；
> 5. **该指数与同主题其他指数的差异在哪里**（编制方式、成分股数量、加权方式、行业分布），用一句话说明“为什么是这个指数而不是那个”；
> 6. 当前折溢价率，若为跨境ETF须单独标注“QDII溢价不适用常规阈值”。
> 
> 不确定的数据必须写“数据缺失”，不得用“大约”“可能”替代。

**改造要点：** 原模板用“排除龙头”迫使AI进入非共识区域，这一技巧保留，但排除对象从“直接半导体制造”改为“规模最大的前3只ETF”——因为ETF的规模头部效应极强，头部产品往往已是市场共识的载体，排除它们才能触及真正有差异的选择。新增的第5项是ETF筛选的灵魂：**同一个主题下跟踪不同指数的ETF，其风险收益特征可能截然不同**，不追问指数差异的筛选等于没有筛选。规模区间阈值和清盘警戒线来自A股ETF的实务标准。

### 1.2 轮动方向候选筛选（替代原“Deep Research主题筛选”）

**可直接使用的提示词：**

> 基于截至 {日期} 的公开市场数据，从A股行业/主题ETF中筛选 **5—8个下月值得关注的方向**，要求兼顾进攻与防守。对每个方向输出：
> 
> - 对应ETF代码与跟踪指数；
> - 该方向近1月、近3月、近6月涨跌幅在全部行业主题ETF中的排名分位；
> - 近20日日均成交额（流动性门槛：**≥5000万元**，低于此值标注“流动性不足”）；
> - 该方向当前的核心驱动逻辑（政策/景气/资金）与最大的反向风险各一条；
> - 用一句话说明该方向与其余入选方向之间的**相关性或对冲关系**。
> 
> 输出为表格。不给出“买入/卖出”判断，只做方向梳理与数据并列。

**改造要点：** 原模板的“预期年化回报区间”在ETF场景下应删除或弱化——ETF的回报几乎完全由指数决定，让AI给出“回报区间”极易滑向编造。替换为**排名分位、流动性门槛和方向间相关性**，这三者是可从公开数据复核的事实层信息。进攻/防守兼顾的要求在ETF轮动中通常通过“行业ETF+红利/债券ETF”的组合来实现，可让AI显式标注每个方向属于哪一侧。

## 二、深度基本面分析类：从“公司叙事拆解”改为“指数画像—产品画像”两阶段

### 2.1 第一阶段：指数画像（替代原“bring me up to date”的业务叙事部分）

**可直接使用的提示词：**

> 以一位指数研究员的审慎标准，分析 **{指数名称/代码}** 。**不要**把它当作ETF产品介绍，**不要**罗列基金公司信息。本轮只做指数本身：
> 
> 1. **编制画像**：编制方（中证/国证/交易所等）、加权方式（市值/等权/因子）、成分股数量、调样频率、单一样本权重上限；
> 2. **结构画像**：前10大成分股合计权重，前3大行业及各自占比，判断属于“高度集中（>70%）/ 中等集中（50—70%）/ 较分散（30—50%）/ 高度分散（<30%）”；
> 3. **估值画像**：当前PE、PB及近5年历史分位（注明口径），说明当前估值在历史上的位置意味着什么、不意味着什么；
> 4. **收益—风险画像**：近3年年化收益、年化波动率、最大回撤，并与沪深300对比；
> 5. **这个指数“不包含什么”** ：明确列出该指数在行业或风格上的系统性遗漏，以及这种遗漏在什么市场环境下会构成显著拖累。
> 
> 本轮不评价任何具体ETF产品。数据缺失处标注“数据缺失”。

**改造要点：** 原模板的核心技巧是“从当前价格隐含的预期切入，逆向拆解什么已经定价”。ETF版本将这一逻辑移植到指数层面：**估值分位回答“贵不贵”，结构画像回答“暴露了什么”，第5项回答“没暴露什么”** 。“不包含什么”这一问是对ETF叙事偏差的直接对冲——主题ETF的宣传材料天然倾向于强调指数“包含了哪些热门赛道”，而系统性遗漏往往是回撤的主要来源。集中度阈值来自A股ETF的通行分析标准。

### 2.2 第二阶段：产品画像（替代原“建模输入交接”）

**可直接使用的提示词：**

> 承接上一步对 **{指数}** 的分析，现在比较跟踪该指数的 **{2—4只ETF}** ，回答“如果通过ETF表达这个指数观点，产品层面要付出多少代价”。逐项输出：
> 
> | 维度                    | ETF-A | ETF-B | ETF-C |
> | --------------------- | ----- | ----- | ----- |
> | 管理费+托管费合计             |       |       |       |
> | 最新规模（亿元）及区间判断         |       |       |       |
> | 年化跟踪误差（近1年）           |       |       |       |
> | 近1年跟踪偏差（ETF收益 − 指数收益） |       |       |       |
> | 近3月日均成交额              |       |       |       |
> | 当前折溢价率                |       |       |       |
> | 前10大持仓合计权重            |       |       |       |
> 
> 对跟踪误差给出定性判断：**<0.3% 优秀 / 0.3—0.8% 良好 / 0.8—1.5% 一般 / 1.5—2.5% 较差 / >2.5% 跟踪失效**（行业ETF可适当放宽半档）。
> 
> 最后用一段话回答：**如果只选一只长期持有，代价最小的选择是哪一只，代价在哪里；如果做波段，流动性和折溢价的重要性如何改变排序。**

**改造要点：** 原模板要求“留下可用于后续交互式估值模型的建模输入”，ETF版本替换为**产品层面的代价比较**。ETF不存在“估值建模”的空间，它的“成本”体现在费率损耗、跟踪误差、买卖价差和折溢价中。跟踪偏差与费率的关系是一个被广泛使用的检查点：TD 应接近 −（管理费+托管费），显著差于该值意味着存在额外损耗。A股股票ETF的合同标准通常是日均跟踪偏离度绝对值不超过0.2%、年化跟踪误差不超过2%，提示词中要求AI将实际值与这一合同基准对照，比笼统的“跟踪误差大不大”更可复核。当前A股宽基/行业ETF的最低费率档为管理费0.15%+托管费0.05%，提示词不预设“越低越好”，而是让AI给出费率与行业均值的对比，保留判断空间。

## 三、量化研究框架类：从“四段式个股框架”改为“ETF轮动策略定义框架”

### 3.1 月频行业ETF轮动策略提示词

**可直接使用的提示词：**

> **角色**：你是一位熟悉A股ETF轮动研究的研究助理，任务是**把策略定义翻译为可回测的规格**，不评价策略优劣，不预测收益。
> 
> **输入约束**：
> 
> - 调仓频率：月频（每月最后一个交易日信号，下一交易日执行）；
> - 备选池：{列出ETF代码或“全部A股行业ETF，剔除规模<2亿及日均成交额<3000万者”}；
> - 持仓数量：{N}只，等权或按{权重规则}；
> - 交易限制：单边换手不超过{ X% }，计入单边{ Y }bps交易成本。
> 
> **策略逻辑需明确以下信号的定义与参数**：
> 
> 1. 动量信号：{如“近20日涨跌幅排名”}；
> 2. 趋势过滤：{如“收盘价是否高于60日均线”}；
> 3. 波动率调整：{是否按近20日年化波动率倒数加权}；
> 4. 市场状态过滤：{如“沪深300低于200日均线时，权益ETF总仓位上限降至X%，剩余配置债券ETF或现金”}；
> 5. 现金/防御资产：{债券ETF代码或“现金”}。
> 
> **输出要求**：先输出一张“策略规格表”，包含上述全部参数的可回测定义；再输出一段伪代码或Python框架代码（使用backtrader或vectorbt），代码须包含数据清洗、信号计算、调仓执行和净值计算四段。**不输出任何回测收益数字**，回测由用户自行运行。

**改造要点：** 西南证券的Codex实践表明，ETF轮动策略的自然语言提示词需要覆盖调仓频率、备选范围、持仓数量、交易限制，以及动量、趋势、波动率、市场过滤、权重和现金仓位等构件。这一结构被完整保留。关键改造在于**明确禁止AI输出回测收益数字**。让AI“顺手跑一个回测”在ETF场景下风险极高——它可能调用错误的数据源、忽略交易成本、或直接编造净值曲线。提示词的定位应当是**规格定义器**，而不是回测执行器；把执行交给用户可控的本地环境，是可复现性的基本前提。

A股ETF轮动还需要一个原模板中不突出的构件：**现金/防御资产**。行业ETF轮动在A股的一个常见失败模式是满仓穿越下行区间，而“市场过滤 + 债券ETF/现金仓位”是比单纯选行业更底层的风控开关。

## 四、风险管理与决策审计类：从“个股下单检查”改为“ETF交易前置检查”

### 4.1 下单前ETF结构化检查清单

**可直接使用的提示词：**

> 我计划买入 **{ETF代码}** ，方向 **{买入/加仓}** ，计划价 **{价格}** ，数量 **{份数/金额}** 。请按以下规则逐项检查并输出 **PASS / WARN / BLOCK**：
> 
> **A. 产品层**
> 
> 1. 最新规模是否 **<2亿元**？是 → BLOCK（清盘风险）。
> 2. 近20日日均成交额是否 **<3000万元**？是 → WARN；**<1000万元** → BLOCK（流动性不足以执行计划数量）。
> 3. 当前折溢价率：A股ETF绝对值 **>0.5%** → WARN；**>1%** → BLOCK（追高溢价）。跨境ETF（QDII）溢价 **>2%** → BLOCK（QDII溢价回归风险显著高于境内ETF）。
> 
> **B. 计划层**
> 4. 单笔最大亏损 = |计划价 − 止损价| × 数量。若未提供止损价 → WARN（计划不完整）。
> 5. 该笔金额占总资金比例是否超过 **{用户预设单票上限}** ？超过 → BLOCK。
> 6. 该ETF所属行业/主题是否与现有持仓中的某只ETF高度重叠（跟踪同一指数或前10大持仓重合度>50%）？是 → WARN（伪分散）。
> 
> **C. 纪律层**
> 7. 是否处于用户预设的 **连亏冷静期**？是 → BLOCK。
> 8. 本次交易的理由是否可以用一句话写成 **“如果……那么……”** 的可证伪形式？不能 → WARN（理由不可检验）。
> 
> 输出表格：检查项 | 结果 | 触发规则 | 一句话说明。最后给出汇总判定。**不输出“该不该买”的判断。**

**改造要点：** 原模板的核心设计——**AI检查的是“已经形成的交易计划是否违反用户自己定的纪律”，而不是替用户做买卖决定**——被完整保留。ETF场景下增加了产品层的硬性前置条件：规模和流动性是ETF独有的“可执行性”问题，一只跟踪误差很低的ETF如果日均成交额不足，计划数量本身就无法以合理价格成交。折溢价阈值区分了境内ETF和QDII：境内ETF的正常折溢价范围通常在 ±0.2% 左右，超过0.5%即需警惕；而QDII因海外市场时差，持续溢价是结构性问题，不能简单套用境内阈值，设定2%的BLOCK线是对这一差异的显式承认。“伪分散”检查是ETF组合中一个容易被忽略的集中度来源：持有三只不同名称的ETF但跟踪同一指数或持仓高度重合，并没有增加分散，只是增加了交易成本。

### 4.2 ETF持有期偏差审计（替代原“认知偏误审计”）

**可直接使用的提示词：**

> 以下是我对 **{ETF代码}** 的持有理由和当前状态。请以**偏差审计员**的角色，对照以下清单逐项检查，指出我的推理在何处可能被扭曲：
> 
> - **叙事偏差**：我是否在用“这个赛道长期有前景”替代“这个指数当前估值已经反映了多少前景”？
> - **锚定效应**：我的止损/止盈参考点是否锚定在买入价或某个历史高点，而不是指数估值分位或基本面变化？
> - **处置效应**：我是否倾向于卖出盈利的ETF、保留亏损的ETF，而两者的指数逻辑并没有发生对应的变化？
> - **规模/流动性忽视**：我是否因为某只ETF“费率最低”而选择了流动性不足的产品，实际上把费率节省消耗在了买卖价差上？
> - **主题混淆**：我是否把“行业景气”等同于“ETF必然上涨”，忽略了指数编制方式（如等权 vs 市值加权）对收益路径的巨大影响？
> 
> 对每项给出：**是否触发（是/否/信息不足）** + 触发依据（引用我提供的内容或指出缺失信息）+ 一条**可执行的复核动作**（不是“再想想”，而是“查什么数据、看什么指标”）。

**改造要点：** 原模板的偏误清单来自一般投资心理学，ETF版本将每一条偏误**锚定到ETF特有的决策陷阱**上。叙事偏差在ETF场景中尤其隐蔽，因为主题ETF的营销语言天然鼓励“赛道叙事”；处置效应的ETF版本表现为“卖宽基、留主题”，而两者的风险特征完全不同；规模/流动性忽视直接对应“最低费率陷阱”——在费率差距不过0.1—0.2个百分点的情况下，买卖价差和冲击成本可能轻易吞噬这一优势。每项偏误要求输出**可执行的复核动作**，是把审计从“提醒”变成“工作流”的关键一步，与原报告中“规则优先于目标”的原则一脉相承。

## 五、贯穿性的ETF提示词原则（替代原“元规则”）

**第一，ETF提示词必须同时约束“指数层”和“产品层”，不可偏废。** 只问“这个ETF怎么样”得到的输出，要么滑向基金公司介绍，要么滑向行业前景散文。有效的ETF提问天然是两段式的：先让AI把指数拆开（估值分位、结构、遗漏），再让它比较产品（费率、跟踪、流动性、溢价）。

**第二，把“数据缺失”设为合法的、被要求的输出。** A股ETF的规模、成交额、跟踪误差、折溢价都是高频变动的数据，AI在离线状态下极易用训练数据中的陈旧值冒充当前值。提示词中应显式写入“数据缺失时写‘数据缺失’，不得用‘大约’‘可能’替代”，并把时效和口径（“截至{日期}”“近20日”“近1年”）写进输入约束。简书的ETF模板将“不允许使用‘可能’‘大约’”“缺少数据时写明‘数据缺失’”作为输出规则，是可直接复用的纪律条款。

**第三，ETF提示词应尽量把判断转化为可对照的阈值，而不是留给AI“发挥”。** 跟踪误差的“优秀/良好/一般/较差”分档、规模区间的“健康/警戒/清盘”、折溢价的“正常/警惕/BLOCK”，这些阈值本身可以讨论，但**有阈值远胜于无阈值**。没有阈值的“跟踪误差大不大”得到的是形容词；有阈值的“与0.3%/0.8%/1.5%分档对照”得到的是可复核的判断。

**第四，跨境ETF和行业ETF需要独立的约束条款，不能与宽基ETF共用一套提示词。** QDII的溢价机制、时差导致的净值滞后、外汇额度对申赎的影响，与境内宽基ETF是完全不同的风险结构；行业/主题ETF的集中度判断标准（前10大权重>70%属常见）也不同于宽基（>70%则属异常集中）。上一轮报告的“通用最优提示词”预设，在ETF领域尤其不成立——**提示词的专业性恰恰体现在对产品类型差异的显式承认上**。

**小结：** 将投资提示词从个股迁移到国内ETF，最关键的改造不在于术语替换，而在于**承认ETF是一种“双层决策工具”** ：第一层判断指数值不值得暴露，第二层判断哪只产品以最小的代价提供这种暴露。四类提示词分别对应这一双层结构的不同切面——筛选类做双层收敛，深度分析类分两阶段执行，量化框架类把策略规格化而不代替回测，风控类在下单前同时检查产品可执行性和计划纪律。贯穿始终的原则与原报告一致：**约束越清晰，输出越可验证；越是试图让AI“大胆判断”，越容易得到流畅而不可靠的叙事。**
