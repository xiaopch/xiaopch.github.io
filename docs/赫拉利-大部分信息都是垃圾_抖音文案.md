# 赫拉利：你每天刷的90%信息都是垃圾

（口播/激情解说，语速稍快）

**【开头 · 抓眼球】**

你有没有这种感觉？每天刷手机刷到吐，但好像什么都没记住？

历史学家赫拉利说了一句大实话：**现在这个世界，大部分信息都是垃圾。**

**【中间 · 讲道理】**

过去，信息很稀缺，能找到一本书就跟捡到宝一样。但现在呢？我们被信息淹没了。

而且最恐怖的是——那些疯狂推送给你看的内容，很多都被人为地灌满了贪婪、愤怒和恐惧。

为什么？因为所有平台都在抢你的注意力。什么内容最能让你停下手指？就是那些让你焦虑的、生气的、害怕的。

你以为是你在刷手机？其实是手机在刷你。

**【核心 · 颠覆认知】**

赫拉利说，我们得学会"信息节食"。

因为大多数人都有一个致命的误解——**以为信息越多，就越接近真相。**

但真相是什么？真相是昂贵的、复杂的、让人不舒服的。讲真话很难，很难传播。

反而是那些编出来的东西——幻想、故事、谎言——最容易让人相信，最容易把人聚在一起。

**信息的本质不是传递真相，而是连接。**

谁最会编故事，谁就最会控制你。

**【结尾 · 发人深省】**

所以，下次刷到让你暴怒或者焦虑的视频，问自己一句：

我是在获取真相，还是在被别人连接？

**放下手机，去读一本好书吧。**

关注我，带你读懂这个世界的真相。
